## Formalife organization-wide AI execution policy

This repository inherits the organization-wide AI execution policy from:

`formalife/formalife-company-os/AI_EXECUTION_ROUTER.md`

Operational rules:

- ordinary Chat remains the preferred control/decision surface when it can complete the work reliably;
- Work/Codex are used only when they provide a material execution advantage;
- a Chat handoff to Work/Codex must specify exact surface, model, reasoning effort, complete prompt and return condition;
- repository-local instructions may add project-specific execution constraints but must not silently reverse founder-level routing, canonical-source discipline or human approval gates;
- copied prompt/chat context never outranks current canonical repository/source-of-truth files;
- external send/publication/spend/live-pricing/irreversible or material commitments require the existing human gates unless explicitly authorized.

Do not copy the full router into this repository. Keep this adapter plus only the repository-specific rules needed here.
